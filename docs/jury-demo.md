# Jury demo

Four beats, one synthetic site (12 orders, 5 posts, 4 crews). Not SVARZ.

1. **FIFO.** Calendar queue: overlaps, skill mismatches, setup zeros, missed dues.
2. **GREED.** Constraint-aware candidate. Say: “the system built a feasible schedule from declared rules”, not “AI solved it”.
3. **Checker.** Independent pass: coverage, precedence, posts, crews, skills, aux, calendars, dues, frozen, spares.
4. **Disruption.** Delay a spare / move one operation. Frozen agreed work stays. Then load the broken plan and show exit 2.

Speak only measured fixture numbers from `repairflow demo`.
