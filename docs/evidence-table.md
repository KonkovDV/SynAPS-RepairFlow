# Сводная таблица сравнения решателей

Функция `repairflow.evidence_table.build_evidence_table` (и скрипт `python tools/pack_evidence.py`) строит машиночитаемую сводную таблицу по нескольким прогонам разных решателей на одной и той же входной задаче `RepairFlowProblem`.

Выходной формат соответствует схеме `repairflow.evidence_table.v1`. Строки таблицы упорядочиваются по метке решателя и сохраняют все проверочные атрибуты каждого прогона:

- `status`, `claim_status`, `solver_class`, `kernel_status` и `optimality_scope`;
- булев признак `verified_feasible` и код выхода `exit_code`;
- отпечатки `input_hash`, `config_hash` и `result_hash`;
- версию RepairFlow, закреплённый коммит SynAPS, уровень доказательности `claim_level` и происхождение данных `data_provenance`;
- единые пересчитанные показатели (`makespan_minutes`, `total_tardiness_minutes`, `total_setup_minutes`, `coverage`, загрузка постов).

## Гарантии сопоставимости

1. **Единый вход.** Попытка объединить в одну таблицу результаты с различающимися `input_hash` отвергается с ошибкой.
2. **Единые знаменатели метрик.** Их считает `metrics.compute_metrics`, не внутренний счётчик решателя. Признак проверки равен нулевому коду выхода независимого нотариуса при полном покрытии. Признак оптимальности берётся строго из проверенного статуса строки и никогда не додумывается для эвристических методов.
3. **Запечатывание пакета.** Скрипт `tools/pack_evidence.py` сохраняет `evidence-table.json` вместе с входной задачей, планами, отчётами нотариуса и собственным детерминированным отпечатком таблицы `table_hash`.

Запись показателей, по которым строки таблицы можно сравнивать. Их считает одна и та же функция `metrics.compute_metrics`:

```text
makespan_minutes = (самый поздний end − planning_horizon.start) в минутах
                   0, если назначений нет

total_setup_minutes = сумма setup_minutes по назначениям

total_tardiness_minutes = сумма max(0, конец последней операции работы − due_date)
                          только по работам с due_date и с назначением

coverage = назначенные операции / все операции задачи
           0, если операций нет

знаменатель загрузки постов = sum(max_parallel по постам) × минуты горизонта
```
