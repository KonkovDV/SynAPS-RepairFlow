# ADR-0003: release boundary for pilot readiness

## Decision

Release only as offline/shadow decision support for one repair contour. The generated plan is a candidate for human review, not an instruction to an operational control system.

## Rationale

The current model is a laboratory prototype with synthetic and anonymized-data support. This boundary preserves fail-closed behavior while the project gathers a named process owner, real baseline data, and a pilot agreement.

## Consequences

The README and application must distinguish verified feasibility of a supplied instance from business impact, production deployment, and customer adoption. Any claim about savings, TRL, or deployment requires separately cited evidence.
